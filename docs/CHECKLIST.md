# AI Output Verification Checklist

**Print this page. Keep it nearby when using AI.**

---

## Before You Trust an AI Answer

- [ ] I remember: **AI is not an authority on health, law, or money**
- [ ] I read the full answer slowly, not just skimmed it
- [ ] I circled/flagged every specific claim (names, dates, numbers, quotes, studies)
- [ ] I asked: "How would I verify each flagged claim?"

---

## Verifying Each Claim

For **each** flagged claim:

- [ ] I searched for it independently (browser, not AI)
- [ ] I found the original source (not a summary)
- [ ] The source is current (check the date)
- [ ] The author/source is qualified on this topic
- [ ] Other independent sources agree
- [ ] No obvious conflict of interest
- [ ] I noted: ✅ Verified | ❌ False | ⚠️ Unverifiable | ⚡ Contradicted

---

## Cross-Checking with Other AIs

- [ ] I asked 2+ different AIs the same question
- [ ] I compared their core claims side by side
- [ ] I flagged any disagreements
- [ ] I verified disputed claims against non-AI sources

---

## Citing AI Output Honestly

If using AI output in your work:

- [ ] I named the AI tool and date
- [ ] I included the prompt (or summary)
- [ ] I marked each claim: verified / unverified / contradicted
- [ ] I did NOT cite AI as a primary source

---

## Red Flags — Stop and Investigate

- [ ] AI cites a study/paper that doesn't exist in search
- [ ] AI gives a specific quote you can't find anywhere
- [ ] AI states a statistic with no source
- [ ] All AIs agree but no primary source exists
- [ ] Claim sounds too perfect / too convenient
- [ ] Source is a blog, forum, or social media only
- [ ] Medical/legal/financial advice presented as fact
